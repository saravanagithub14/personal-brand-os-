# Task 002: MVP Content System

## Goal
Build the core content operating system.

## Implement
- BrandProfile
- BrandVoice
- ContentPillar
- ContentItem
- ContentVersion
- ContentApproval
- Project
- Content editor
- Calendar
- Main dashboard

## Acceptance criteria
- [ ] User can manage brand profile
- [ ] User can manage brand voice
- [ ] User can create/edit content
- [ ] User can create content ideas
- [ ] User can assign pillars
- [ ] User can schedule draft content
- [ ] User can move/reschedule calendar items
- [ ] User can create content from a project
- [ ] Content versions are stored
- [ ] Approval history is stored
- [ ] Dashboard shows real database data

## Out of scope
- Real social publishing
- Advanced analytics
- Automated news ingestion
