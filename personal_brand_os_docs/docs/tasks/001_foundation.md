# Task 001: Foundation

## Goal
Create the Django foundation without implementing the complete product.

## Implement
- Django project
- domain apps
- environment configuration
- PostgreSQL
- Redis
- Celery worker and beat
- Docker development environment
- authentication
- base templates
- static/media configuration
- `.gitignore`

## Acceptance criteria
- [ ] Application starts locally
- [ ] Database connection works
- [ ] Redis connection works
- [ ] Celery worker starts
- [ ] Celery beat starts
- [ ] Login/logout works
- [ ] Secrets are environment-based
- [ ] Tests run successfully

## Out of scope
- Social publishing
- Advanced AI agents
- Analytics
- News scraper
