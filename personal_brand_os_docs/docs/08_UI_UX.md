# UI/UX Specification

## Style
Modern SaaS dashboard. Clean spacing, cards, charts, tabs, badges, responsive layout, dark/light mode.

Desktop-first but mobile friendly.

## Sidebar
- Dashboard
- Calendar
- Content
- Ideas
- AI Studio
- Scripts
- Research
- AI News
- Projects
- Social Accounts
- Analytics
- Media
- Brand
- Settings

## Top bar
- Global Search
- Notifications
- AI Assistant
- Profile

## Dashboard
Show:
- brand summary
- followers
- posts this month
- scheduled posts
- drafts
- content ideas
- engagement
- today's tasks
- content calendar
- AI news brief
- content pipeline
- analytics
- recommendations

## AI Studio
Actions:
- Generate Idea
- Write Post
- Create Script
- Repurpose
- Analyze News
- Improve Content
- Build Calendar

## Content editor
Left: editor.
Right: AI assistant.

AI actions:
- Improve hook
- Rewrite
- Shorten
- Expand
- Make technical
- Make beginner friendly
- Generate CTA
- Generate hashtags
- Fact check
- Create thread
- Create Reel
- Create carousel
- Repurpose

Allow selected-text transformations.
